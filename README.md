# Tugas Akhir Web - Dicoding

Repositori ini berisi proyek akhir untuk kelas Dasar Pemrograman Web dari Dicoding. 
Website ini dibangun sebagai portofolio pribadi dengan menerapkan gaya desain Neo-Brutalism.

## Teknologi yang Digunakan
- HTML5 Semantik (`<header>`, `<nav>`, `<main>`, `<aside>`, dll.)
- CSS3 murni
- Layout menggunakan Flexbox (tanpa `float`)
- Desain responsif menyesuaikan ukuran layar perangkat
